# XEI.ItemGenerator 1.5.0 – Notes de version

## Fonctions de cette version

- **Essai gratuit automatique.** L'add-on accepte le code d'essai reçu par e-mail après la demande sur le site :
  il est valable 30 jours à compter de l'envoi, dans n'importe quelle société.
- **Langue turque.** Formulaires, menus, messages et la fenêtre *Générer les articles* sont en turc : avec
  SAP Business One en turc, l'add-on s'utilise en turc.
- **Langues du programme** : italien, anglais, allemand, français, espagnol et turc.

## Installation

- Nécessite XEICore 1.2.2, inclus dans le package.
- S'installe avec l'Extension Manager de SAP Business One, comme décrit dans le guide d'installation.
