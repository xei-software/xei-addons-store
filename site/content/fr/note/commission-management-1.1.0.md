# XEI.CommissionManagement 1.1.0 – Notes de version

## Fonctions de cette version

- **Licence XEI avec essai gratuit.** L'add-on fonctionne avec un code de licence XEI, qu'un
  superutilisateur colle depuis le menu *Licenza* (Licence) de l'add-on. L'essai gratuit se demande sur le
  site : le code arrive par e-mail et est valable 30 jours à compter de l'envoi, dans n'importe quelle
  société.
- **Autorisation « Configurazione »** (Configuration). Elle détermine qui peut voir et modifier les options de
  l'add-on, séparément des autres autorisations.
- **Langue turque.** Formulaires, menus et messages sont en turc : avec SAP Business One en turc, l'add-on
  s'utilise en turc.
- **Langues du programme** : italien, anglais, allemand, français, espagnol et turc.

## Corrections de cette version

- Les utilisateurs sans droits de super-utilisateur utilisent les fonctions selon les autorisations qui leur sont
  attribuées.

## Installation

- Nécessite XEICore 1.2.1, inclus dans le package.
- S'installe avec l'Extension Manager de SAP Business One ; au premier démarrage, l'add-on prépare
  lui-même la structure des données.
