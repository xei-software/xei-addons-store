# XEI.ItemGenerator 1.5.0 – Release notes

## Features of this version

- **Automatic free trial.** The add-on accepts the trial code that arrives by email after the request on the
  website: it is valid for 30 days from sending, in any company.
- **Turkish language.** Forms, menus, messages and the *Generate Items* window are in Turkish: with SAP Business
  One in Turkish the add-on is used in Turkish.
- **Program languages**: Italian, English, German, French, Spanish and Turkish.

## Installation

- Requires XEICore 1.2.2, included in the package.
- It is installed with the SAP Business One Extension Manager, as described in the installation guide.
