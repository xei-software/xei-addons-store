# XEI.CommissionManagement 1.1.0 – Release notes

## Features of this version

- **XEI license with free trial.** The add-on works with a XEI license code, which a superuser pastes from
  the add-on's *Licenza* (License) menu. The free trial is requested on the website: the code arrives by
  email and is valid for 30 days from sending, in any company.
- **«Configurazione» authorization** (Configuration). It controls who can view and change the add-on's options,
  separately from the other authorizations.
- **Turkish language.** Forms, menus and messages are in Turkish: with SAP Business One in Turkish the
  add-on is used in Turkish.
- **Program languages**: Italian, English, German, French, Spanish and Turkish.

## Corrections in this version

- Users without superuser authorizations use the functions according to the authorizations assigned to them.

## Installation

- Requires XEICore 1.2.1, included in the package.
- It is installed with the SAP Business One Extension Manager; on first start the add-on sets up its
  data structure by itself.
