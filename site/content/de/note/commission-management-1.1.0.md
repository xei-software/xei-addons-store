# XEI.CommissionManagement 1.1.0 – Versionshinweise

## Funktionen dieser Version

- **XEI-Lizenz mit kostenlosem Test.** Das Add-on arbeitet mit einem XEI-Lizenzcode, den ein Superuser im
  Menü *Licenza* (Lizenz) des Add-ons einfügt. Der kostenlose Test wird auf der Website angefordert: Der
  Code kommt per E-Mail und gilt ab dem Versand 30 Tage in jeder Firma.
- **Berechtigung „Configurazione“** (Konfiguration). Sie regelt, wer die Optionen des Add-ons sehen und
  ändern darf, getrennt von den anderen Berechtigungen.
- **Türkische Sprache.** Formulare, Menüs und Meldungen sind auf Türkisch: Mit SAP Business One auf Türkisch
  wird das Add-on auf Türkisch verwendet.
- **Sprachen des Programms**: Italienisch, Englisch, Deutsch, Französisch, Spanisch und Türkisch.

## Korrekturen dieser Version

- Benutzer ohne Superuser-Rechte verwenden die Funktionen gemäß den ihnen zugewiesenen Berechtigungen.

## Installation

- Erfordert XEICore 1.2.1, im Paket enthalten.
- Die Installation erfolgt mit dem Extension Manager von SAP Business One; beim ersten Start richtet
  das Add-on die Datenstruktur selbstständig ein.
