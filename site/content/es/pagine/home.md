# Soluciones de software XEI

XEI desarrolla soluciones de software listas para usar para empresas: aplicaciones, integraciones y herramientas que
funcionan con los programas y los datos que la empresa ya utiliza. Cada aplicación tiene su página con descripción,
capturas de pantalla, manuales y guía de instalación.

## Por qué elegir las soluciones de software XEI

- **Listas para usar**: se instalan siguiendo la guía y se usan enseguida, sin desarrollos a medida.
- **En el idioma del usuario**: las aplicaciones están disponibles en varios idiomas; los de cada aplicación se
  indican en su página.
- **Documentadas**: para cada aplicación, manual de uso, guía de instalación y notas de la versión.
- **Prueba gratuita**: descárguelas gratis y reciba por correo electrónico un código de prueba válido durante 30 días.

## Cómo empezar

1. Elija la aplicación en la página Descargas y pulse «Descargar gratis».
2. Rellene el formulario y reciba el código de prueba por correo electrónico.
3. Instale el programa siguiendo la guía de instalación.
4. Introduzca el código de prueba en el programa, como se explica en la guía.

Para comprar una licencia, pulse «Comprar» en la página Descargas o escriba a
[license@xeisrl.com](mailto:license@xeisrl.com).
